Viva & Demonstration Guide (Table 2)
(a) Vulnerable Implementation

Located in app.py within function cmdi_inband():

# User input passed directly into shell command string with shell=True cmd = f"ping -n 1 {target_host}" result = subprocess.run(cmd, shell=True, capture_output=True, text=True) return result.stdout # Directly returned to the user
(b) Working Exploit Payload

In the target field, supply command chained payload:

127.0.0.1 && whoami

How it works: The && operator instructs the shell to execute the first command (ping), and upon its completion, immediately execute the second command (whoami or dir). Because the application captures stdout and prints it to the web page, the execution is in-band.

(c) Root Cause

Invoking a system shell with unsanitized user data: Enabling shell=True spawns a command shell (e.g., cmd.exe or /bin/sh), which treats characters like &&, &, ;, and | as command separators, executing arbitrary attacker instructions.

(d) Mitigation Implemented

Dual Defense: Input Validation + Parameterized Execution (shell=False): First, validate the target against a strict regex allow-list. Second, avoid the shell completely by passing arguments as an array (argument vector).

# 1. Allow-list validation if not re.match(r"^[a-zA-Z0-9.-]+$", target_host): raise ValueError("Invalid target format.") # 2. Argument vector without shell invocation arg_vector = ["ping", "-n", "1", target_host] result = subprocess.run(arg_vector, shell=False, capture_output=True)
(e) Other Mitigations from Lecture (Theory)
  • Avoid the shell entirely: Use built-in high-level language programming APIs or libraries (such as Python's socket library or ICMP modules) rather than spawning external OS binaries.
  • Parameterized execution with an argument vector: Ensures arguments cannot be re-parsed as options or chained commands.
  • Strict allow-list validation: Reject any input that does not strictly match expected patterns (IPv4/IPv6 or FQDN format).
  • Least privilege: Run the web server process under a heavily sandboxed, unprivileged service account with no access to system administration binaries.
